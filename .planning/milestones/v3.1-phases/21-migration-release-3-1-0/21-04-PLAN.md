    `SelfTest` — synthetic 64x64 fixtures (D-08 falsifiability style): identical pair → 0 diff px and 0 rects; pair with a 10x10 block changed at (20,20) → one rect that contains (20,20,10,10); the same block with a noise region covering it → classified inside-noise; with a noise region elsewhere → classified outside-noise. Print `AERO_COMPARE_SELFTEST PASS` or throw.

    `Noise -RunDirs <dirA>,<dirB> -Kind showcase|uitest -OutJson <path> [-Merge]` — group files by frame key (showcase: `<Theme>/<Section>/p<N>` from `<Theme>\<Section>-p<N>-c<K>.png`; uitest: `<Component>/<Theme>/<state>` from `<Component>\<Theme>\<state>.png`); reference = first run's c1 (or the file); compare every other capture of that key with `DiffCells(ref, other, 8)`; union the cells, merge 8-connected cells into rects, pad each rect by 2 px (clamped); a dimension mismatch is recorded as `dimensionMismatch`. JSON shape: `{ "<kind>": { "<frameKey>": { "captures": n, "stable": bool, "regions": [ { "x":..,"y":..,"w":..,"h":..,"px":.. } ] } } }`; `-Merge` adds the kind into an existing file instead of overwriting.

    `Compare -BeforeDir -AfterDir -Kind -NoiseJson -DiffDir -OutJson` — before = c1 of the before run, after = c1 of the after run (uitest: the single file); keys only on one side are listed as `missingBefore` / `missingAfter`; per key compute diffPx, pct, maxChannelDelta, rects; classify each rect insideNoise (fully contained in a padded noise region of the same key) or outsideNoise; for any key with diffPx > 0 write `<DiffDir>\<key>.png` = after image dimmed 50% with differing pixels painted #FF00FF and outsideNoise rects outlined 2 px; summary totals (keys, identical, insideOnly, withOutside, missing).

    `ContactSheet -Dirs <before>,<after>,<diff> -Kind uitest -OutDir` — per `<Component>/<Theme>` one PNG grid: one row per state, columns before | after | diff, labels drawn with System.Drawing.

    Commit: `feat(21-04): capture comparison, noise extraction and contact sheets`.
