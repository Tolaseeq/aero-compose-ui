<objective>
Make every state this phase created actually reachable in the running showcase, then gate the phase on a human three-theme x per-state visual sign-off for all three restyled components. Pixel-diff tooling was ruled out at milestone level, so this checkpoint is the only verification the gloss, bevel, recess, rim and glow criteria ever get.

Purpose: the automated Wave-0 guards prove the resolvers return the right values and the source calls the right primitives. They cannot prove the result reads as Aero glass, that hover and focus are tellable apart, or that a focus stroke is not being sliced by a parent clip. Those are the four things this phase is most likely to get subtly wrong, and all four are eye-only.
Output: two updated showcase sections and a recorded human approval (or a defect list routed back to Plans 01-03).
</objective>
