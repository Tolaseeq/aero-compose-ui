<interfaces>
- WM_STYLECHANGING 0x007C: wParam = GWL_STYLE (-16) or GWL_EXSTYLE (-20); lParam → STYLESTRUCT { DWORD styleOld; DWORD styleNew } — writing styleNew before forwarding changes the style that will be applied.
- WM_NCCALCSIZE wParam = 1: rgrc[0] (offset 0, 4 ints) holds the proposed WINDOW rect on entry; whatever is left there on return (with return value 0) becomes the CLIENT rect.
- IsZoomed(HWND) is hand-declared in AeroUser32 (Plan 02). MonitorFromWindow(hwnd, MONITOR_DEFAULTTONEAREST = 2) + GetMonitorInfo(MONITORINFO: rcMonitor, rcWork) are in jna-platform User32.
- Shell32.SHAppBarMessage(DWORD, ShellAPI.APPBARDATA) is in jna-platform: ABM_GETSTATE 4 (result & ABS_AUTOHIDE 1), ABM_GETAUTOHIDEBAREX 0xB with APPBARDATA.uEdge ∈ {ABE_LEFT 0, ABE_TOP 1, ABE_RIGHT 2, ABE_BOTTOM 3} and APPBARDATA.rc = the monitor rect → non-null HWND means an auto-hide bar sits on that edge of that monitor.
- GetSystemMetricsForDpi(SM_CXSIZEFRAME 32 / SM_CYSIZEFRAME 33 / SM_CXPADDEDBORDER 92, dpi) (hand-declared, Plan 02).
- WM_NCACTIVATE 0x0086: forwarding it with lParam = -1 makes DefWindowProc skip the non-client repaint (documented) — use ONLY if Task 3 observes classic caption paint.
- Conflict #3 inputs: 2 px is Windows Terminal's production inset for auto-hide edges (PITFALLS Pitfall 9); no source supports 1 px for this purpose.
- 22-NOTES.md: C1 style values, F9 (whether probe maximize is safe outside a real-input session), baseline frames in `.captures/22-baseline/`.
