Author the two new source-scan gates this milestone owes — VER-01 (gradient end stops are
proportional, never pixel-fixed) and VER-02 (nobody bypasses `aeroSurface()`'s centralized clip
order) — each carrying its own in-file, re-executed fail-then-pass proof (VER-06 via D-08).

**This plan LEADS the phase with a tracer.** Task 1 is a `type="tracer"` slice: it delivers ONE
complete gate end-to-end — pure detector function → comment-stripped real-source scan → in-file
red-on-broken / green-on-clean fixture proof → green inside the normal Gradle suite. That path is
the architecture every remaining gate in this phase (VER-02 here, VER-03 in 20-03, the D-13
contrast regression in 20-04) replicates. It is production-quality, not a spike: it ships as the
permanent VER-01 gate. Proving the D-08 fixture convention once, end-to-end, before three more
gates are written on top of it is the point — D-08 is a `costly` decision (the convention binds all
three new gates), so a shape defect found here costs one commit instead of four.

Purpose: the production code is already compliant (RESEARCH.md: 18 gradient call sites across 9
files, all `size.`-relative; no clip-order bypass anywhere). The work is therefore authoring the
gate plus proving it can fail — NOT fixing production code. A task whose only acceptance criterion
were "the gate passes" would be satisfied vacuously, and that vacuous pass is the exact
false-positive this phase exists to prevent.

Output: two new `*SourceTest.kt` files under `library/src/test/kotlin/com/mordred/aero/verification/`.
